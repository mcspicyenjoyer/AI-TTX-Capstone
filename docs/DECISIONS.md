## ADR-014 - Docker-first scaffold

Accepted for local implementation on 18 September 2026 at the user's request. Use one multi-stage Node 24 container serving the React build and Fastify API, with SQLite in a Docker-managed named volume at `/data`. This resolves ADR-005's local demonstration data location without selecting a Windows user-specific directory. AI remains disabled; no provider or paid operation is introduced.

Compose publishes only to `127.0.0.1`; binding `0.0.0.0` inside the container does not approve LAN exposure. Run as non-root, drop capabilities, keep the application filesystem read-only and exclude everything from the build context except an explicit source/configuration allowlist. Never include token.txt, uploads, credentials or reference packs in an image.

Alternative: native per-laptop Node/npm installations and an approved host data directory. Docker adds image updates, an engine/virtualisation prerequisite, disk usage and volume backup work, but standardises builds across laptops. Git carries code and the lockfile, not Docker volumes or saved exercises. A new clone starts a separate local dataset unless a backup is transferred and restored. Do not remove volumes or overwrite data as part of ordinary startup. Build/test portability is only established once the actual container checks pass.
