## Demo boundaries

This is a facilitator-operated **five-position linear prototype**. The role players and facilitator in this run are assistants; separate authenticated sessions and source-limited role packets test software behaviour, not independent human usability, organisational capability or time savings. Branch recommendations, the final generated ten-position workflow and complete Form B acceptance remain outside this result.

For the demonstration, show saved evidence first and retain text-only continuation while live generation is pending or fails. Explicit review, attach, accept, freeze and release remain separate actions. Application limits still apply: ten extraction requests per intake; ten drafts per facilitator; ten image requests per package; thirty started interpretations and three started AAR calls across the whole dataset. There is no automatic retry, paid API fallback, automatic approval or guarantee of subscription availability. A transferred data archive does not transfer the other laptop's signed-in Codex session, worker processes or environment setup.
